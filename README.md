# KREÖN · site public (kreonpaysage.com)

Version publique du site KREÖN, hébergée sur GitHub Pages avec le domaine kreonpaysage.com.

- `index.html` : générée automatiquement à partir du site publié dans Claude (script `.build_public.py`). Ne pas modifier à la main.
- `img/`, `docs/` : photos et documents PDF du site.
- Les formulaires (devis, visite, SAV…) envoient les demandes vers un tableau Google (variable `KFORM`), importé ensuite dans l'Espace équipe.
